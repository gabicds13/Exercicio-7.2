# Exercício 7.2 — MVC em Python

Execute `python3 controller.py` no terminal do Codespaces. Abra **Ports > 8000 > Open in Browser**.

- **Model**: `model.py` (regras e dados) + `banco.py` (SQLite).
- **View**: `view.py` (interface HTML/CSS).
- **Controller**: `controller.py` (coordena ações HTTP).
- `servidor.py`: servidor web Python padrão, sem instalações.

Funções: buscar livros, consultar preços e estoque, reservar por 24h e cancelar. Dados fictícios e persistência em SQLite. Como projeto de demonstração, a reserva representa um único usuário local.
